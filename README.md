# 들녘 / FIELDLINE

농지·인구·자원·병력 생산 중심의 한국어 육각 전략 게임. 기술 트리 없음. 실제 3D 복셀 지도, 사선 카메라, 클릭할 때만 열리는 하단 고정 정보창.

## 실행

```sh
npm install
npm run dev
```

로컬 주소: http://localhost:4318 . 드래그로 지도 이동, Alt+드래그 회전, 휠/핀치 확대. 유닛 선택 후 우클릭 이동, 우클릭을 누른 채 경유지 지정. 1은 이번 내 턴, 2는 다음 내 턴이며 남은 경로는 유지된다. 같은 유닛을 좌클릭하면 남은 경로만 취소한다. 유닛·도시 정보는 아래 고정 자리, 타일 정보는 그 옆에 열린다. 좁은 화면에서는 타일 카드가 바로 위로 이동한다. 이미지 생성물·외부 모델·텍스처 없이 코드로 그린다. WebGL 2 필요.

GitHub Pages 정적 클라이언트는 `VITE_API_BASE`로 지정한 API 릴레이를 사용한다. 멀티플레이 서버를 직접 열 때는 `FIELDLINE_ALLOWED_ORIGINS`에 Pages 출처를 넣고 `npm start`를 실행한 뒤, Cloudflare Tunnel 등 HTTPS 주소를 `VITE_API_BASE`로 지정해 빌드한다. 브라우저가 PC의 프로세스를 대신 실행하지는 않는다.

이동·공격·건설은 자기 턴에 즉시 적용된다. 공격은 1회이며 이동력 전부 소모, 공격하지 않은 유닛은 이동력 0에서도 인접 공격 가능. 건축자는 건설 1회와 남은 이동력을 소모하고 마지막 건설 후 사라진다. 생산력은 기본 2 + 인구에 보급 불이익을 적용한다. 도시 이름 옆 생산 아이콘/남은 턴 표시. 완성 부대는 도시 타일에 생성되며 점유/수용량 부족 시 완성 상태로 대기한다.

20×20 전체 지도를 처음에 맞춰 보여주며, 네 방향 모두 지도 밖은 바다다(동서 연결 없음, 2026-09-06 방장 규칙). 미탐사 칸은 실제 지형과 무관한 옛 지도 무늬로 가린다. 카메라 위치·확대만 이 탭에 저장하므로 관측 갱신이나 새로고침에 시야가 초기화되지 않는다. 유닛 선택 시 흰색 이동 경계와 빨간색 공격 경계, 지도 위 도시·유닛 체력바를 표시한다. 적에 커서를 올리면 상성·지형·보급을 적용한 양측 피해 예상이 나온다. 건축자와 아군 전투 유닛은 함께 있을 수 있다.

상단 우측에 초시계·일시정지·턴 마치기, 아래에는 세력별 아이콘·현재 차례·외교 관계와 외교/시장 버튼이 있다. 설정에서 전역 턴 시간(10~300초, 기본 60초), 이 기기의 음소거/볼륨을 변경한다. 일시정지는 인간 방장 p1만 가능하며 양측의 명령과 시계를 함께 멈춘다. 합성 효과음, 병종별 총격·돌격·포격·피격·느린 파괴와 건축자 망치질 연출을 사용한다. 소리는 첫 사용자 입력 후 활성화되며 설정에서 테스트할 수 있다.

도시는 인구 기반 자연 확장과 영토 구매, 생산력으로 성벽 건설·증축(1~3레벨)을 지원한다. 성벽은 도시 체력과 방어력을 높이고 반경 2칸에 턴당 한 번 사격할 수 있다. 시장은 식량/자원 매매와 유닛 판매를 지원한다. 상대 도시나 상단 세력 아이콘을 누르면 동일한 외교창이 열린다. 선전포고·공개비난·우호 선물·10턴 동맹·5턴 평화 협정이 있으며, 전쟁 소식은 모든 세력에 전달된다.

거래창은 양쪽의 카드를 추가·제거하고 최종 조건을 검토하는 방식이다. 골드·자원·도시·유닛, 상호 동맹, 내가 또는 상대가 제3세력과의 전쟁에 참여하는 조건을 함께 협상할 수 있다. 상대의 도시/유닛은 관측 중인 대상만 선택할 수 있고 비축량은 공개하지 않는다. 사람 상대는 명시적으로 수락해야 성립하며 제안자의 돈/자원은 예치된다. 거절·취소·만료 시 반환된다. 도시의 수비대는 자동 이전되지 않으며 수도 양도는 승패에 영향을 줄 수 있다.

```sh
npm test
npm run build
npm start
```

개발 서버는 프런트엔드만 자동 갱신한다. 서버 코드 변경은 재시작 필요. 경기는 서버 메모리에만 있으며 재시작하면 초기화된다. 새로고침은 같은 경기에 재접속한다. 서버 재시작 후 새로고침하면 새 연습을 연다.

## 사람과 대화형 에이전트의 대전

메뉴에서 대전을 만들고 초대 코드를 상대에게 전달한다. 상대가 참가하면 방장이 시작한다. p1 → p2 순서로 각각 최대 60초. `activePlayer`만 명령 가능하며 시간 초과나 턴 마치기는 자기 도시 경제/생산을 정산하고 상대에게 넘긴다. p2 종료 후 규칙 NPC가 행동하고 라운드 번호가 증가한다. 네 문명은 인간 p1, 직접 조종하는 대화형 에이전트 p2, 규칙 기반 p3/p4다. NPC는 자기 관측을 토대로 농지·생산·탐색·병력 회복·상성·외교를 판단한다. 추가로 방어형 도시국가와 주기적으로 병력을 생성하는 파괴 가능한 야만인 거점이 있다. 연습 p2는 3초에 차례를 넘기는 수동 상대이며 추론 AI가 아니다. 자동 대화형 모델 연결이나 결제는 포함하지 않는다.

CLI는 통신만 한다. `npm run game -- help`로 명령 목록 확인. `join <초대코드>`가 반환한 본인 matchId/token을 `FIELDLINE_MATCH`와 `FIELDLINE_TOKEN` 환경 변수로 다음 호출에 전달한다. `FIELDLINE_URL` 기본값은 `http://127.0.0.1:4318`.

- `game observe`: 현재 본인 시야의 상태
- `game orders '<JSON>'`: `{turn, orders: [{unitId, action, target?: {q,r}}], production?: [{cityId,type}]}`. 도시 사격은 `{cityId,action:'cityBombard',target:{q,r}}`, 성벽 생산은 `type:'walls'`.
- `game transaction '<JSON>'`: 시장·영토·외교 (`{turn,action,...}`)
- `game ready <turn>`: 자기 턴 정산 후 상대에게 넘김
- `game wait <revision>`: 상태 변경 대기

MCP: `node tools/mcp.mjs`로 stdio 서버를 실행한다. 도구는 `game_join`, `game_observe`, `game_orders`, `game_transaction`, `game_ready`, `game_wait`. 계정 전역 MCP 설정을 임의로 바꾸지는 않았다. 세션 인증만 메모리에 유지하며 클라이언트는 관측 기록을 저장하지 않는다.

HTTP: `POST /api/matches`, `POST /api/join`, `GET /api/matches/:id`, `POST /api/matches/:id/{start,orders,ready,settings,transactions}`, `GET /api/matches/:id/wait?revision=N`. 참가 후에는 `Authorization: Bearer <본인 토큰>` 필요. 숨겨진 전체 게임 상태를 반환하는 경로는 없다.

복합 거래의 전송 형식:

```json
{"turn":1,"action":"offerDeal","factionId":"p2","give":{"gold":20,"resources":{"iron":1},"units":[],"cities":[],"warAgainst":null},"receive":{"gold":0,"resources":{},"units":[],"cities":[],"warAgainst":"p3"},"alliance":false}
```

실제 관측의 현재 턴·대상 ID를 사용한다. 위 예시는 상대의 p3 참전을 요청하는 형식 설명이며 경기 전략이 아니다. `acceptProposal` / `rejectProposal` / `cancelProposal`은 관측에 표시된 `proposalId`를 사용한다. 사람 상대는 본인 차례에 수락하며, 거래 실행 전 모든 자산과 조약을 다시 검증한다.

## 개척과 규칙 NPC

개척자는 생산력 40, 이동력 2, 시야 3의 비전투 유닛이다. 도시에서 생산한 뒤 다른 도시로부터 최소 4칸 떨어진 무주지/자기 영토의 평지에서 ‘도시 세우기’를 누른다. 이동력이 남아 있어야 하며 즉시 인구 1 도시가 생기고 개척자만 소모된다. 아군 전투 부대와 같은 칸에서 호위받을 수 있다. 건축자는 농지·자원 개발 전용이며 개척자와 구분된다. 민간 유닛 둘은 같은 칸에 설 수 없다.

NPC는 자기 시야만 사용한다. 부상 병력은 안전한 곳에서 방어하며 회복하고, 포병은 사격 이동력을 남기며 사거리를 유지한다. 집중 공격·병종 상성·지역 병력 우세를 따지고, 필요한 자원이 부족하면 금고 여유를 남겨 시장에서 구매한다. 내정이 안정되면 알려진 지형의 식량·자원을 평가하고 개척자를 호위해 최대 3개 도시까지 확장한다. 이것은 p3/p4 등의 규칙 플레이이며 p1/p2의 대화형 직접 조종을 대신하지 않는다.

적 영토라는 이유만으로 보급이 끊기지는 않는다. 산·적 병력과 통제 구역·적 도시로 실제 연결이 차단되어야 포위 불이익이 누적된다. 공성 피해는 체력·경험치·편제·보급·도하·성벽을 반영하며 포병은 공성에 35% 이점이 있다. 기본 병종 공격력과 상성 수치는 유지했다.

## 경기 중 공정성

에이전트는 자기 관측 API만 보고 직접 판단한다. 파일 메모·관측 기록 저장, 전략 코드/솔버, 시뮬레이션, 다른 에이전트, 서버 파일이나 상대 상태 확인은 금지한다. 개발/검증 코드는 경기 중 사용하지 않는다. 서버는 시야·자원·명령·시간 제한을 강제하지만, 호스트 권한이 있는 에이전트의 파일 접근 금지까지 OS 수준에서 봉쇄하지는 않는다. 기존 대화 문맥에 과거 관측이 남는 한계도 있다.

미탐사 지형·비옥도·자원 매장지까지 숨긴다. 탐사한 지형은 기억하지만, 시야 밖 병력의 현재 상태와 변경된 적 영토/시설은 공개하지 않는다. 사용자가 허용한 게임 내 마지막 관측 표시는 UI와 API에 동일하게 제공한다. 외부 전략 노트 허용을 뜻하지 않는다. 포격 발사 좌표는 공개하고, 명중 시 맞은 적의 칸은 그 턴에 드러난다. 이후 다른 시야 밖 칸으로 이동하면 마지막 좌표만 남는다. 규칙과 수치는 게임 메뉴의 ‘게임 규칙’에 설명되어 있다. 수목은 장식이며 별도 숲 지형 효과는 없다.

## 구현과 검증

`shared/rules.js`: 순환 좌표/기본 규칙. `shared/combat.js`: 서버와 UI가 공유하는 전투 공식. `server/engine.mjs`: 서버 판정. `server/world.mjs`: 세계 생성. `server/npc.mjs`: NPC 관측 기반 판단. `server/deals.mjs`: 거래 검증/예치/동의. `src/world3d.js`: 관측만 받는 복셀 모형/경계선. `src/Board3D.jsx`: 카메라/선택/렌더러 수명. `src/Panels.jsx`: 하단 정보. `tools/`: 전략 없는 전송 클라이언트.

74개 테스트는 즉시 행동/경유 경로/교대 턴/ZOC/가림막/합병/경험치/농지/자원/도시 스폰/보급/도하/기한/승패/영토/거래/외교, HTTP 인증/초대/비공개 명령, 실제 stdio MCP 호출, 20×20 순환 지형과 탐사, 성벽/도시 사격, 일시정지 권한, 전투 예상, NPC/야만인 거점, 자산 이전/동맹/참전의 동의와 원자적 처리, 3D 경계·지형 깊이·병종별 모션, 카메라 설정과 첫 소리 재생을 다룬다. 개척자 생산·정착·호위, NPC 회복/집중 공격/자원 구매, 시야 공정성, 16라운드 NPC 확장 검증도 포함한다. 변경 전에는 60초 제한으로 13턴 직접 플레이한 뒤 경기 조종을 끝내고 개발 단계로 분리했다. 브라우저 QA 기록은 `memory/2026-09-05.md`. 완주 경기의 장기 밸런스와 실제 기기 스피커 출력은 추가 검증이 필요하다.

## 2026-09-06 방장 규칙 업데이트

- 지도는 평평한 20×20 판이다. 동서가 이어지지 않으며 영토·보급·사거리·경로 모두 지도 끝에서 끊긴다.
- 이동력: 창병·머스킷병·포병·건축자·개척자 4, 기병 10, 상인 5.
- 도시 수비 반격: 인접한 비포병 유닛이 도시를 직접 공격하면 `도시 반격 기본(20) + 인구 × 계수(3)`만큼 ±12% 무작위 피해를 되돌려 준다. 포병은 여전히 반격을 받지 않는다.
- 초석 유지비는 자기 턴 시작 때 미리 낸다. 낸 부대는 그 턴에 재고가 0이어도 사격할 수 있고, 턴 종료 정산은 두 번 걷지 않는다.
- 완성된 유닛은 도시 칸이 막혀 있으면 인접한 자기 영토 칸에 나타난다. 모든 칸이 막힌 경우에만 완성 대기한다.
- 생산창의 각 병종 줄 옆에 골드 즉시 구매 버튼이 있다(확장 규칙). 조건은 생산 예약과 같다.
- 설정 → 전투 밸런스: 방장이 병종별 기본 공격력, 근접 반격 배율, 도시 반격 기본·인구당 계수를 바꾼다. 연습·실험 경기는 언제나, 대전은 일시정지 중에만.
- 메뉴 → 실험 모드 연습: 확장 규칙 연습을 즉시 시작하고, 지도 칸을 클릭해 내 편/야만인 유닛을 원하는 체력으로 소환하거나 선택한 유닛을 제거한다. API는 `transaction {action:"spawn", type, factionId, target:{q,r}, hp}` / `{action:"removeUnit", unitId}`이며 실험 경기에서만 허용된다.
- 확장 대전 설정 → 턴 방식 `동시 턴`: 모든 사람·API 좌석이 같은 초시계 안에서 동시에 행동한다. 명령은 즉시 적용되고 같은 칸은 먼저 움직인 쪽이 차지한다. 전원 준비 완료(`행동 완료`)이거나 시간이 끝나면 규칙 문명이 행동한 뒤 한 번에 정산된다. 관측의 `turnMode`, `activeSeats`를 참고하며, 준비를 마친 좌석의 `activePlayer`는 `waiting`으로 표시된다. 방장은 대기실·일시정지 중에 설정에서 바꿀 수 있다.
- 턴 시계는 서버 시각 기준으로 보정되어 기기 시계가 어긋나도 60초를 넘겨 표시하지 않는다.
- 화면 그리기 오류가 나면 흰 화면 대신 복구 화면이 나오고, 같은 경기로 다시 그릴 수 있다.
